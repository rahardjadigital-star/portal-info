PORTAL INFORMASI DOKUMEN — TEMPLATE DEMO

Cara pakai:
1. Buka index.html di browser.
2. Klik "Aktifkan Mode Edit".
3. Klik teks yang ingin diubah lalu ketik langsung.
4. Klik "Selesai Edit" setelah selesai.
5. Tombol "Simpan Data (.json)" menyimpan isi data.

Catatan:
- Ini hanya template demo / mockup.
- Tidak menggunakan logo, nama, atau branding resmi pemerintah.
- Jangan gunakan untuk menyamarkan data sebagai hasil verifikasi resmi.
